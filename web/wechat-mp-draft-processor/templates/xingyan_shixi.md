# 【行研实习】账号草稿处理配置

## 标题转换规则

### 前缀规则
| 原始标题特征 | 添加前缀 |
|-----------|---------|
| 含"量化" | `量化实习 | ` |
| 含"金融工程"/金融 | `实习｜` |
| 含"行研" | `行研实习 | ` |
| 含"投行" | `投行实习 | ` |
| 含"基金" | `基金实习 | ` |
| 含"证券" | `证券实习 | ` |
| 其他 | `实习｜` |

### 精简规则
- 移除年份信息（如"2026"、"2027"）
- 移除过长的团队/公司修饰语（如"魏建榕团队"）
- 保留核心信息：公司/机构名 + 岗位/类型

### 标题长度限制
- 最大 64 字符（微信 API 限制）
- 超长时截断并添加"…"

## 投递方式隐藏规则

### 文字模式处理
删除以下关键词开头的段落（含其后续内容）：
- `简历投递`
- `投递方式`
- `联系方式`
- `申请方式`
- `如何投递`
- `邮箱投递`
- `招聘流程`中含有邮箱/联系人的部分

删除以下关键信息：
- 邮箱地址（如 `hr@xxx.cn`）
- 联系电话（如 `130xxxx`）
- 联系人姓名
- 公司地址
- 投递二维码图片

### 长图模式处理
1. OCR 识别长图中的"投递方式"区域
2. 定位该区域的起止坐标（Y轴）
3. 裁剪掉该区域
4. 将剩余部分重新拼接为新长图

### OCR 定位关键词
用于在长图中定位投递区域：
- `投递方式`
- `简历投递`
- `联系方式`
- `申请方式`
- `如何申请`
- `简历发送`
- `联系我们`
- `招聘流程`

## 固定推广模板

模板存储在 `templates/xingyan_shixi.html`，由原始微信文章提取并保留格式。

### 模板特点
- 保留原始微信 HTML 格式和样式
- 图片使用素材库永久链接（mediaId URL）
  - 下箭头引导 GIF: `mmbiz_gif`
  - 信息表推广图 PNG: `mmbiz_png`
- 关键词占位符：`{keyword}`

### 图片素材管理
素材链接存储在 `promotion_media_ids.json`，包含：
- 下箭头引导 GIF mediaId
- 信息表推广图 PNG mediaId

### 占位符
- `{keyword}`: 文章关键词编号（如 `0427`）

## 关键词编号规则

### 生成规则
- 格式：`MMdd`（月日，4位数字）
- 如 4月27日发布 → `0427`
- 如 5月1日发布 → `0501`

### 冲突解决
- 如果当天已有文章使用该编号，追加序号：`0427a`, `0427b`
- 或使用时间戳：`042701`（4位日期+2位序号）

## 摘要生成规则

### 自动提取
1. 从正文中提取前 100-120 字符
2. 移除 HTML 标签和格式标记
3. 确保不被截断在句子中间

### 手动覆盖
- 支持通过 `--digest` 参数指定摘要
- 如果自动提取不满意，可以手动覆盖

## 作者字段
- 默认：`行研实习`
- 最大 16 字符

## 输出文件

### draft.html
处理后的正文 HTML，供上传脚本读取。

### draft.json
处理后的元数据，包含：
- `title`: 处理后标题
- `digest`: 摘要
- `keyword`: 关键词编号
- `author`: 作者
- `content_source_url`: 原文链接
- `mode`: 文章模式（`text`/`long_image`）
- `original_title`: 原始标题
